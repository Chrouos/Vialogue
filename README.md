# Vialogue

把一句話，交給海。

**[開啟海灘試玩](index.html)**。用新版 Chrome 或 Edge 開啟即可，不需要安裝套件、啟動伺服器或登入。

目前完成的是有日夜、雲、浪花與海鷗的本機海灘，加入頭頂表情、示例旅人回應及會被浪抹去的沙畫。信件採信紙／信冊介面，保留核心體驗：點選沙地移動與坐下、等待示例漂流瓶、寫信與照片、依序讀信、添信、返航與收藏。附近角色與來信皆為示例，沒有連接真人或 Google，信件與草稿只存在目前瀏覽器。

想直接體驗收信，在左下角「試玩工具」選「讓示例瓶靠岸」。這是明確的試玩操作，正常等信仍沒有保證到信時間。
