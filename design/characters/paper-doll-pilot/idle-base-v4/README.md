更新日期：2026-10-16。

使用者指出由大張 master-source 重新縮製的兩個人物眼睛、嘴巴不清楚，偏好 idle-source 那套影格。本版直接使用該套素材已認可的 idle-finished/frames/frame-00.png，不再從大張基準圖重新縮放或減色。

- combinations/ha-fa-oa.png 是原待機影格的檔案複製，SHA256 完全相同。
- combinations/ha-fa-ob.png 僅替換同一影格背心內的 325 個色塊像素，不修改頭髮、臉、輪廓、手腳或其他位置。
- 顏色使用先前 ImageGen 服裝換色稿所採用的藍灰色階。本輪沒有重新生成任何人物。
- 頭部、服裝以外的像素與透明度皆逐像素驗證相同，共用圖層也能精確重組原圖。
- 更新的組合圖直接位於原 combinations 資料夾，對照圖直接更新上層 combinations-review.png。

本版仍只是一個髮型、一張臉和同一件背心的兩個配色，不代表完成完整換裝或逐格動畫分層。原待機影格、來源圖與 GIF 保留不動。

原 master-source.png 保留作高解析造型參考；目前遊戲尺寸的頭身與臉部可讀性，以既有待機影格為準。不能以「頭部在兩個新版本之間相同」取代檢查它是否真的符合認可的待機造型。
