# 短偏分角色：八款遊戲小臉試作

傷心兩款已由[新版 v2](../expression-runtime-v2/README.md)修訂，其餘六款沿用本版。

- [放大臉部對照](faces-closeup.png)
- [遊戲原尺寸](native-size.png)
- [全身兩倍對照](full-body.png)

由左至右，上排為一般、開心、超開心、為難；下排為傷心、超傷心、害羞、生氣。這是依已確認八款頭肩稿重新生成的小尺寸眉眼嘴試作，實際小臉造型尚待確認，未取代已認可圖片。

內建 ImageGen 依 layout-reference.png 的固定人物與 expression-eight-v1/expressions.png 的情緒重新整理像素，原稿存於 source.png、提示詞存於 prompt.txt。build_review.py 只取眉眼嘴區域並量化至既有 30 色加兩個紅暈色，合成至已認可短偏分人物。128 × 160 畫布、原透明輪廓、特徵區域外的髮型身體與衣服像素均保持原樣；原始 hb-fa-oa.png 檔案未改動。

已輸出 frames/00.png 至 07.png，八張檔案各有差異，檢查紀錄在 qa.json。這些結構檢查不能證明情緒辨識度；放大與原尺寸人工檢視後，超開心較明顯，但一般與開心、傷心與超傷心的眉嘴細節仍很細，淚痕在現有尺寸未能明確保留。此限制仍待處理，不能宣稱八款已具備同等可讀性。

目前僅試作短偏分、苔綠背心的靜態版本，未擴展至其他髮型、通用臉部圖層或 idle 動畫。頭肩稿的確認不等於這輪小臉已獲確認。
