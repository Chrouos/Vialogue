## 本次發現與處理

舊髮型參考圖的差異不全是頭髮，還包含 y=65..67 的頸部與原背心領口。直接交換整片頭部會把舊衣服像素帶入新穿搭。build_combinations.py 只套用 y<65 的髮型差異，保護目前一般表情區域，保留新衣服 y>=65 的全部像素。因此領口與肩膀使用各套已認可服裝本身，不帶入舊背心。

## 驗證結果

- 15 張圖片各有差異，同為 128 × 160，透明度僅為 0 或 255。
- 同一套衣服在五種髮型下，y>=65 的身體、衣領、褲子與鞋子逐像素相同。
- 同一髮型在三套衣服下，y<65 的頭部逐像素相同，固定的一般表情像素保留。
- 短偏分的三張輸出與已認可 modern-outfits-v2 三張原圖逐檔相同。
- 全部腳底最低像素位於 y=147；頭部與軀幹檢查點均屬同一連通區，沒有被空白列分開。
- 所有來源檔案 SHA-256 不變。

人工檢視總覽與領口放大圖，目前未見明顯的髮尾斷縫、舊背心領口殘留或頭部尺寸不一致。這是靜態畫面檢查結果，非對未製作動作的保證。技術紀錄見 qa.json，人工檢視紀錄見 visual-review.json。
