# 固定像素的待機動畫

日期：2026-10-16。使用者已確認「GIF 變好了 可以」，採用此固定像素的待機方向。這項認可不代表完整紙娃娃動畫已完成。

使用者指出先前 GIF 像素會亂跑。原因是採用了各自生成的四格，髮型、衣服與陰影每格都有不同細節。

本版改用單張已選定的短偏分人物，以固定像素組成四格：待機、小幅抬升、眨眼、回到待機。抬升是鞋子以上整體平移一像素，不重畫紋理；眨眼僅取用已認可閉眼影格的小區域。這是簡單待機試作，尚非胸口與衣服各自運動的細緻呼吸動畫。
