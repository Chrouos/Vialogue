# 換裝比例校正 v2

更新日期：2026-10-16。

使用者認可 idle-clips/contact-sheet.png 與 idle-finished/frames/frame-02.png 的像素感，指出舊換裝圖頭大、笑容怪異、風格不一致。因此以 idle-finished 的角色比例及像素處理結果作為後續基準。

[對照圖](comparison.png)：左上是使用者選定的待機風格，左下是舊換裝，其餘為本輪校正後的八種組合。

修正了兩個已確認的處理問題：舊換裝高 119 像素，待機基準高 112 像素；舊頭髮單獨放大到 43 像素寬。新組合統一為 112 像素高，頭髮為 34 像素寬，臉的圖層由 38 降為 27 像素高。移除底層重疊的光頭，重新設定臉、頭髮與衣領對位。

部位色盤採待機的 30 色，額外加入四個藍灰色以保留第二套穿搭，禁止抖色。詳見 [數值檢查](qa.json)。

這只是比例與處理流程的修正，並未消除獨立生成部位造成的造型差異。對照圖中的五官、肩膀和服裝輪廓仍與待機不同，不能宣稱畫風已完全統一。現有待機影格不改動。

後續應以已選定的待機造型重新拆分與對齊部位，再確認基礎臉與微笑表情；舊換裝素材不作為擴充款式的造型基準。本輪八種校正版仍需使用者審核，未定為正式素材。
