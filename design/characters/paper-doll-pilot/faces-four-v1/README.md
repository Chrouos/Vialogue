## 四種方向

- A 安靜：沿用已認可的半瞇開眼、平嘴。
- B 溫和：沿用笑眼提案，閉合彎眼與上揚嘴角。
- C 好奇：較圓的睜眼、抬眉、小圓嘴。
- D 倔強：較重直眉、較窄的開眼與小抿嘴。

## 來源與處理

C、D 的 ImageGen 原稿保存在 source.png，提示詞為 prompt.txt。route 為 host-image_gen；未取得可核實的模型名稱與費用。A 使用已認可素材，B 使用 face-b-v2 的五官稿。

眉眼與嘴形依原待機的平移對位、0.20289855 縮放及 30 色色盤取樣，保留細線條覆蓋率並排除洋紅背景，避免小尺寸曲線被清理成相同平線。只合成三個五官範圍，原頭身透明輪廓、其他像素及既有素材均不改動。

qa.json 確認四款在各髮型下均為不同圖像、範圍外逐像素相同、輪廓相同、原十張檔案雜湊不變。這些數值不代表新款美感已獲確認。
