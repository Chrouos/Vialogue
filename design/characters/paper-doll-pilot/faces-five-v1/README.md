# 五款神情試作

依最新回饋改為 `-.-`、`^_^`、無口、憂鬱、溫柔，撤下好奇與倔強。五款實際造型尚待使用者確認。

- [臉部放大](faces-closeup.png)
- [完整人物對照](comparison.png)
- [原尺寸對照](native-size.png)：128 × 160 畫布，人物高約 112 像素。
- [五髮型交叉對照](all-hairstyles.png)

平直閉眼、彎曲閉眼、睜眼無嘴、下垂眉眼與小幅微笑是五款的主要區別。縮小後的憂鬱眉眼與溫柔嘴角仍需人工判斷是否喜歡，不能只靠放大圖確認。

原稿由 ImageGen 依已認可人物生成於 source.png；build_faces.py 僅取樣眉眼與嘴部區域，再合成至既有人物。保留原畫布、輪廓、頭身比例與臉部區域外的像素，不使用重新生成的身體。原始 combinations 內的十張已認可圖片保持不變。

本資料夾 combinations 內有 50 張靜態提案（5 髮型 × 5 神情 × 2 背心配色）。不是兩套獨立服裝，尚未製作表情動畫，也尚未成為所有方向通用的紙娃娃臉層。qa.json 記錄圖片數量、各神情不同、臉部區域外與透明輪廓一致等檢查。
