## 範圍與結果

- 目前是一個髮型、一張臉、同款背心的綠色與藍色版本，並非兩套完整衣服或八種換裝。
- 同一份基準圖作為身體來源；只將背心內部 297 個像素替換成藍色，其餘像素完全相同。
- 兩個版本的頭髮、臉、嘴形、身體輪廓、手腳與站姿均逐像素一致。
- 輸出共用 128 × 160 畫布，人物高 112 像素，不單獨放大頭或臉。
- 共用底圖與兩個背心色塊圖層能精確重組兩個輸出，詳見 qa.json。
- 原待機影格與 GIF 不改動。

ImageGen 執行了背心換色的參考圖編輯；Forge 工具負責去背、共用縮放與色盤。最後只採用服裝區域的編輯結果，其他區域沿用基準像素。提示詞保存在 outfit-prompt.txt；route 為 host-image_gen，未取得可核實的模型名稱與金額。

目前只驗證共用人物換裝不改變比例，尚未完成可獨立替換的髮型、基礎臉、完整衣服或逐格換裝動畫。所有新輸出仍待使用者視覺確認。
