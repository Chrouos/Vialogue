# 八種情緒試稿

[八款頭肩表情對照](expressions.png)

依使用者確認的種類，以上一輪自然表情研究的人物畫風製作。由左至右：

- 上排：一般、開心、超開心、為難。
- 下排：傷心、超傷心、害羞、生氣。

一般保持平靜；開心以自然微笑呈現；超開心讓臉頰帶動眼睛瞇起並張嘴笑，避免刻意的 `^^` 眼形。為難採不對稱眉眼與苦笑。傷心視線往下；超傷心增加含淚眼眶與少量淚痕。害羞用避開視線、抿嘴小笑與淡淡泛紅；生氣用收緊眉頭與抿嘴呈現。

使用內建 ImageGen，參考 expression-study-v1/expressions.png，完整提示詞存於 prompt.txt。八種情緒與本輪頭肩造型已於 2026-10-19 獲使用者確認。尚未整合紙娃娃圖層或製作動畫。已認可的角色組合與 idle 動畫不變。

## 尺寸檢查

後續已另做[短偏分人物的八款小臉試作](../expression-runtime-v1/README.md)，實際遊戲尺寸造型仍待確認。

由 build_size_review.py 裁切既有原稿並縮製 32、48、64 px 頭像，共 24 張，原稿保持原樣。使用面積縮圖、每張 32 色、無抖色；放大檢視採最近鄰。

- [32 px 原尺寸](size-review/32px-native.png)與[放大檢視](size-review/32px-enlarged.png)：接近現有遊戲人物頭部尺度，超開心仍明顯，但一般／開心及傷心／超傷心的細節容易合併，紅暈和淚痕流失。
- [48 px 原尺寸](size-review/48px-native.png)。
- [64 px 原尺寸](size-review/64px-native.png)：較能保留表情差異，適合作為頭像尺寸參考。

這是尺寸可行性對照，未宣稱可直接縮圖完成遊戲五官。遊戲小臉仍需依已確認原稿另外整理眉眼嘴的像素，不放大已認可角色的頭身比例。所有縮圖含原有米白底，未製作透明臉層。檢查紀錄在 size-review/qa.json。
