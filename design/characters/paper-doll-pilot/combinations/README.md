# 目前換裝驗證

本資料夾保留五款髮型與原背心的十張素材。最新現代服裝搭配請看[15 種一般表情站姿驗證](../outfit-hair-validation-v1/README.md)。

目前共五種已認可靜態髮型，各搭配綠、藍背心，共十張圖片。

| 代碼 | 髮型 |
|---|---|
| ha | 原始髮型 |
| hb | 短偏分 |
| hc | 微蓬後梳 |
| hd | 微捲短髮 |
| he | 低束小髮髻 |

檔名格式為 h?-fa-oa.png 或 h?-fa-ob.png。fa 是同一張基礎臉，oa、ob 是同件背心的綠、藍配色。配色不同不代表已完成兩套完整衣服。

髮型 A 的綠背心圖直接複製已認可的待機影格；其他髮型沿用相同身體與保護的五官。採用紀錄與重建指令見 ../mens-hair-options-v2/README.md。

目前只有短偏分的固定像素待機方向獲認可。其餘動態、獨立臉型、純髮型圖層、完整穿搭分層仍未完成。舊八款封存於 ../archive/rejected-initial-combinations，canonical-v3 已停用。
