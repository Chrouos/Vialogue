# 現代日常穿搭：三套靜態試作

第一套與第三套已依回饋改為 [v2：T-shirt＋牛仔褲、短外套＋短褲](../modern-outfits-v2/README.md)，第二套沿用本版。

- [遊戲原尺寸](native-size.png)
- [與原款背心比較](with-original.png)

服裝方向依使用者要求改為現代，人物像素畫風仍保留原有年代感。

1. 寬鬆米白襯衫、藍牛仔褲、白色帆布鞋。
2. 灰綠針織外套、白色圓領上衣、深色直筒褲、米白休閒鞋。
3. 深藍短外套、淺色上衣、灰寬褲、深色休閒鞋。

目前三套實際造型待確認。這是三套完整穿搭，不是原款背心的重新配色。沿用短偏分髮型與暫用 v4 的一般表情；頭部第 0 至 64 列從已認可圖檔原樣保留，衣服、褲子與鞋子由新原稿處理。

source.png 由內建 ImageGen 依 layout-reference.png 修改服裝，完整提示詞存於 prompt.txt。build_review.py 去除洋紅底、以預乘透明度的面積縮圖縮至 128 × 160，再套用共用 40 色衣物色盤，無抖色；頭部保留既有顏色，不參與新色盤量化。因此全身顏色總數可高於 40，實際統計見 qa.json。三套最低不透明像素都在 y=147，與原人物腳底基準一致；服裝輪廓可依款式不同。

frames/ 內為三張透明 PNG，目前未拆成獨立上衣、褲子、鞋子圖層，未擴展至其他髮型或八款表情組合，也未套用 idle、坐下與走路。數值檢查只確認檔案尺寸、透明度與頭部保留，不代表衣服造型已獲認可。表情改善仍保留於專案 TODO，本輪不修改表情。
